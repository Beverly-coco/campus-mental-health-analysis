# 特征说明文档

## 一、特征概述

本模块提取的多模态特征包括三大类：行为特征、文本特征、生理特征。特征融合后形成512维统一输入向量，用于校园心理健康智能评估与预警系统的深度学习模型训练。

---

## 二、行为特征（20维特征）

### 2.1 基本统计特征
| 特征名 | 类型 | 说明 |
|--------|------|------|
| record_count | 数值 | 学生行为记录总条数 |

### 2.2 消费相关特征
| 特征名 | 类型 | 说明 |

| daily_avg_consumption | 数值 | 日均消费金额（元） |
| daily_avg_frequency | 数值 | 日均消费频次 |

| total_consumption | 数值 | 统计周期内总消费金额 |
| total_frequency | 数值 | 统计周期内总消费频次 |
| canteen_visits | 数值 | 食堂消费次数 |
| supermarket_visits | 数值 | 超市消费次数 |
| consumption_regularity | 数值 | 消费规律性（0-1） |
| daily_consumption_cv | 数值 | 日消费变异系数 |

### 2.3 门禁相关特征

|--------|------|------|

## 三、文本特征（229维）

### 3.1 基础文本特征（9维）
| 特征名 | 类型 | 说明 |
|--------|------|------|
| text_count | 数值 | 学生发布文本总数 |
| total_words | 数值 | 文本总词数 |
| avg_words_per_text | 数值 | 平均每条文本词数 |
| positive_count | 数值 | 积极情绪文本数量 |
| negative_count | 数值 | 消极情绪文本数量 |
| neutral_count | 数值 | 中性情绪文本数量 |
| positive_ratio | 数值 | 积极情绪文本比例 |
| negative_ratio | 数值 | 消极情绪文本比例 |
| neutral_ratio | 数值 | 中性情绪文本比例 |

### 3.2 Word2Vec词向量特征（100维）
| 特征名 | 类型 | 说明 |
|--------|------|------|
| w2v_0 ~ w2v_99 | 数值 | Word2Vec生成的100维词向量，表示文本语义信息 |

**生成方法：**
- 使用Gensim Word2Vec模型训练
- 向量维度：100
- 窗口大小：5
- 训练轮次：10
- 对学生所有文本的词向量取平均

### 3.3 TF-IDF关键词特征（120维）
| 特征名 | 类型 | 说明 |
|--------|------|------|
| tfidf_0 ~ tfidf_119 | 数值 | TF-IDF提取的120维关键词权重 |

**生成方法：**
- 使用Scikit-learn TfidfVectorizer
- 最大特征数：200（实际生成120维有效特征）
- 过滤条件：min_df=2, max_df=0.95

## 五、融合特征（512维）

### 5.1 融合策略
采用加权融合策略，根据不同特征类型的重要性分配权重：

| 特征类型 | 权重 | 原始维度 | 融合后维度 |
|----------|------|----------|------------|
| 行为特征 | 30% | 21 | 84 |
| 文本特征 | 40% | 229 | 313 |
| 生理特征 | 30% | 53 | 116 |
| **总计** | **100%** | **303** | **512** |

**说明：** 原始特征总维度为303维（21+229+53），融合时根据各类型权重分配填充维度至512维。

### 5.2 标签定义
情绪评估等级分为4类：

| 标签 | 编码 | 说明 | 判定规则 |
|------|------|------|----------|
| normal | 0 | 正常 | 文本积极且生理正常 |
| mild | 1 | 轻度异常 | 不满足焦虑/抑郁条件 |
| anxious | 2 | 焦虑倾向 | 文本消极或生理焦虑 |
| depressed | 3 | 抑郁倾向 | 生理状态为抑郁 |

### 5.3 数据集划分
| 数据集 | 样本数 | 比例 |
|--------|--------|------|
| 训练集 | 350 | 70% |
| 测试集 | 150 | 30% |

## 六、数据处理方法汇总

### 6.1 缺失值处理
| 数据类型 | 处理方法 |
|----------|----------|
| 行为数据 | 线性插值 + 中位数填充 |
| 文本数据 | 删除空文本 |
| 生理数据 | 中位数填充 |

### 6.2 异常值处理
| 数据类型 | 处理方法 | 阈值 |
|----------|----------|------|
| 行为数据 | 3σ原则 | μ±3σ |

### 6.3 标准化处理
| 数据类型 | 处理方法 |
|----------|----------|
| 行为特征 | MinMax归一化（0-1） |
| 文本特征 | Word2Vec/TF-IDF自带标准化 |
| 生理特征 | StandardScaler标准化 |
| 融合特征 | StandardScaler标准化 |

## 七、特征与情绪关联性分析

| 文本长度 | ↓减少 | ↓↓显著减少 |
| 社交话题 | ↓减少 | ↓↓显著减少 |

### 7.3 生理特征与情绪关联
